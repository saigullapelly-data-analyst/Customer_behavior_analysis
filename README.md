# 🛍️ Customer Shopping Behavior Analysis

A complete end-to-end Data Analytics project that analyzes customer shopping behavior using **Python, PostgreSQL (NeonDB), SQL, and Power BI** to uncover valuable business insights from transactional data.

---

## 📌 Project Overview

This project explores customer purchasing behavior using a dataset containing **3,900 customer transactions** across multiple product categories.

The objective is to identify customer spending patterns, product preferences, subscription trends, and revenue opportunities that can support data-driven business decisions.

# 🧹 Data Cleaning & Preprocessing (Python)

Performed using **Pandas** in Google Colab.

### Steps Performed

- Imported dataset using Pandas
- Explored data using:
  - `head()`
  - `info()`
  - `describe()`
- Checked missing values
- Filled missing Review Ratings using median values
- Renamed columns using snake_case
- Created new features
  - Age Groups
  - Purchase Frequency
- Removed redundant columns
- Prepared clean dataset for SQL analysis
- Loaded cleaned dataset into PostgreSQL (NeonDB)
